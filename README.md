# BOTD Admin App

React + Firebase control panel for managing the live BOTD website without changing the public website design.

## Folder Structure

- `src/` - React admin app, dashboard sections, Firebase services, hooks, and styles.
- `public/` - Static assets served by Vite.
- `android/` - Capacitor Android wrapper for mobile app builds.
- `dist/` - Production web build output, generated by `npm run build`.
- `firestore.rules` - Firestore access rules for website/admin collections.
- `storage.rules` - Firebase Storage rules for posters, videos, sponsors, and registration uploads.
- `database.rules.json` - Realtime Database rules for live contestants/vote leaderboard data.

## Firebase Data Contract

- Website voting and leaderboard use Realtime Database `contestants`.
- Admin contestant changes also mirror to Firestore `teams` for backwards compatibility.
- Website/admin shared Firestore collections include `categories`, `judges`, `sponsors`, `posters`, `videos`, `registrations`, `contacts`, and `settings`.
- Page content is controlled through `adminContent/seasonPage`, `adminContent/eventsPage`, `adminContent/votingPage`, and `adminContent/rulesPage`.
- Season snapshots are stored in Firestore `seasons`.

## Core Features

- Secure Firebase email/password admin login.
- Protected dashboard routes.
- Real-time contestant add/edit/delete and visibility controls.
- Real-time sponsors CRUD with ordering and visibility controls.
- Season content editor plus saved season snapshots.
- Registration and contact data tables with search/filter/status controls.
- Voting controls for vote count, leaderboard visibility, voting open/closed state, announcement text, and celebration trigger.
- Posters and testimonial videos upload/manage controls.
- Activity log and undo support for supported edits.
- Mobile-ready dashboard layout and Capacitor Android support.

## Firebase Setup

1. Create a Firebase Auth admin user with email/password login.
2. Put the project config in `.env` using `.env.example` as the template.
3. Deploy Firestore rules from `firestore.rules`.
4. Deploy Storage rules from `storage.rules`.
5. Deploy Realtime Database rules from `database.rules.json`.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Android App

```bash
npm run android:sync
npm run android:open
```

The Android project uses Capacitor with hash-based routing so dashboard navigation works safely inside the WebView.
